# FrameWatch

Клієнтський монітор продуктивності для **Minecraft 1.7.10 / Forge 10.13.4.1614**, орієнтований на GT New Horizons.

[Завантажити останню версію](https://github.com/kvxshenyjbetxn/framewatch/releases/latest) · [Повідомити про проблему](https://github.com/kvxshenyjbetxn/framewatch/issues)

## Можливості

- FPS, час кадру та статистика плавності, зокрема 1% low.
- Окремі графіки часу кадру, FPS і використання RAM.
- Відомості про пам’ять Java, збирання сміття (GC) та фази роботи клієнта.
- Налаштування вигляду, масштабу, прозорості й розташування панелей.
- Українська та англійська мови інтерфейсу.
- Експорт історії вимірювань у CSV.

## Встановлення

1. Завантаж файл `framewatch-<версія>.jar` зі сторінки [останнього релізу](https://github.com/kvxshenyjbetxn/framewatch/releases/latest).
2. Закрий Minecraft і поклади файл у папку `mods` свого ігрового інстансу. Якщо оновлюєш мод, прибери попередній JAR.
3. Запусти гру та зайди у світ.

Мод встановлюється **тільки на клієнт** — додавати його на сервер не потрібно. Під час оновлення налаштування зберігаються.

## Керування

| Клавіша | Дія |
| --- | --- |
| **F7** | Відкрити налаштування |
| **F8** | Показати або сховати HUD |
| **F10** | Зберегти історію вимірювань у CSV |

Клавіші можна змінити в **Options → Controls → FrameWatch**. HUD автоматично ховається у меню; приховування не зупиняє збір показників.

## Налаштування

Натисни **F7**, щоб обрати показники й графіки, змінити вигляд або перемістити панелі. Доступні готові набори **Minimal**, **Graph** і **Full**.

Мова змінюється окремо від мови гри: **F7 → Appearance → Mod language → Українська**.

Корисні команди:

| Команда | Дія |
| --- | --- |
| `/fw settings` | Відкрити налаштування |
| `/fw move` | Перемістити панелі мишею |
| `/fw preset minimal` | Увімкнути мінімальний набір показників |
| `/fw preset graph` | Увімкнути набір із графіком часу кадру |
| `/fw preset full` | Увімкнути повний набір показників |
| `/fw help` | Показати всі команди |

Налаштування зберігаються у `config/framewatch.cfg`, а CSV-файли — у `framewatch/exports` у папці ігрового інстансу. Дані нікуди не надсилаються.
